# Bus Eléctrico Isla de Maipo

Aplicación Android de prueba: mapa Santiago–Talagante–Isla de Maipo, ubicación local opcional y marcadores de referencia.

**Aviso:** No incluye todavía seguimiento de buses ni envío de GPS a un servidor. No confundir los marcadores con recorridos oficiales.
